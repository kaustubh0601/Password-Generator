# Password Generator Web Application

This is a web-based password generator application that allows users to create secure passwords based on their specific requirements.

# Live Demo
Check out the live version of the application here: https://kaustubh0601.github.io/Password-Generator/

# Key Features

1. Customizable Password Length
  Users can generate passwords based on a custom length. The password length is visible on the UI.

2.Interactive Slider
  A user-friendly slider allows you to increase or decrease the password length easily.

3.Character Type Selection
  Users can choose to include uppercase letters, lowercase letters, numbers, and symbols in the generated password.

4.Password Strength Indicator
  The UI displays the strength of the generated password in real-time.

5.Copy to Clipboard
  With a single click, you can copy the generated password for immediate use.

# Technologies Used

1. HTML for structuring the web page
2. CSS for styling the UI
3. JavaScript for handling password generation logic

# How to Use
1. Adjust the length of the password using the slider.
2. Select the types of characters you want to include (uppercase, lowercase, numbers, symbols).
3. The password strength will be displayed based on your selections.
4. Click the Generate Password button to create a password.
5. Copy the generated password by clicking the Copy to Clipboard button.
